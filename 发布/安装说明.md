# 电工电子实训 · 安卓版（v1.3）

## 文件

```
发布\电工电子实训-v1.3.apk     ← 直接装到手机
```

- 包名：`com.esim.platform`
- 大小：4.25 MB
- 最低系统：Android 6.0（API 23）
- 目标系统：Android 15（API 35）

## 怎么装到手机

**方式一：微信/QQ 传文件**
把 apk 发到「文件传输助手」，在手机上点开 → 选择「用其他应用打开 / 安装」→ 允许安装未知来源应用。

**方式二：数据线**
手机连电脑 → 把 apk 拷到手机存储 → 用手机上的文件管理器点开安装。

**方式三：adb（开发者）**
```bash
adb install -r 发布\电工电子实训-v1.3.apk
```

> 首次安装系统会提示「未知来源」，在弹窗里允许一次即可。

## v1.3 新增

- **⚙ 服务器地址设置**：顶栏齿轮 → 填后端地址 → 测试连接 → 保存。
  填了地址就能登录、跨设备同步；留空即纯离线。**改地址不用重新打包**。
- **竖屏取景优化**：手机竖屏改用更陡的俯角 + 更小边距，面包板占屏更大
- **允许 HTTP 明文**：可以填 http://192.168.x.x:3001 这类局域网地址

### 手机连电脑后端（同一 Wi-Fi）

1. 电脑上启动后端，并允许局域网访问：
   `powershell
   ='0.0.0.0'; npm run server
   `
2. 查电脑 IP：ipconfig，比如 192.168.1.100
3. 手机 App 里点 ⚙，填 http://192.168.1.100:3001 → 测试连接 → 保存
4. 之后就能用账号登录、数据同步到电脑上的 SQLite

## 能做什么（离线可用）

- ✅ 3D 面包板、元件拖拽、孔位磁吸、导线连接
- ✅ 并查集拓扑识别、网表生成、节点电压法求解、接线图同构判定
- ✅ 仪表读数、记录数据（**保存在手机本地**）、导出实验报告
- ✅ 双手操作（手指拖动 = 移动元件）

**全部计算都在手机本地完成**，不需要联网、不需要服务器。

## 不能做什么（需要后端）

- ❌ 账号登录、跨设备同步
- ❌ 把记录/报告存到服务器

原因：App 里打包的是前端（WebView + WebGL），后端是 Node 服务，跑不到手机上。
要让账号和数据可用，需要把 `server/` 部署到一台公网服务器（HTTPS），
然后在 App 里配置该地址后重新打包 —— 见下一节。

## 如果要连自己的服务器

1. 把后端部署到公网（Nginx + HTTPS）
2. 修改 `src/api/client.js` 顶部：
   ```js
   const RAW_BASE = 'https://你的域名'
   ```
3. 重新构建并打包：
   ```powershell
   $env:Path = "D:\hclaw\node;" + $env:Path
   Push-Location D:\y\1
   npm run build
   npx cap sync android
   $env:JAVA_HOME = "D:\y\1\.cache\jdk21\jdk-21.0.12.1+1"
   $env:ANDROID_HOME = "C:\Users\HH\AppData\Local\Android\Sdk"
   cd android; .\gradlew.bat assembleDebug
   Pop-Location
   ```
   产物在 `android\app\build\outputs\apk\debug\app-debug.apk`

## 重新打包的环境说明

- JDK 21 已下载到 `D:\y\1\.cache\jdk21\`（Capacitor 7 的 Android 库用 Java 21 编译，JDK 17 会报"无效的源发行版：21"）
- Gradle 8.11.1 已下载到 `D:\y\1\.cache\gradle-8.11.1-bin.zip`，并在
  `android\gradle\wrapper\gradle-wrapper.properties` 里指向本地文件（官方源在国内连不上）
- Maven 依赖走阿里云镜像（已写进 `android\build.gradle`）
- 构建成功后 `.cache` 目录（约 500 MB）可以删掉，下次构建会重新下载
