# 部署详细步骤（从零到手机能用）

> 目标：让平台运行在一台 24 小时开机的云服务器上，得到 `https://你的域名`。
> 之后手机 App 里填这个地址，**电脑关机也不影响**。
>
> 全程大约 **30–60 分钟**（不含备案时间）。

---

## 第 0 步：准备清单

| 需要什么 | 建议 | 备注 |
|---|---|---|
| 云服务器 | 腾讯云 / 阿里云「轻量应用服务器」2核2G | ¥60–100/年（学生机） |
| 操作系统 | **Ubuntu 22.04 LTS** | 别选 CentOS 7（太老） |
| 域名（可选） | 任意 `.top` / `.com` | ¥10–60/年；没有域名也能用 IP 跑通 |
| 电脑 | 你现在这台 Windows | 用来打包上传 |

### ⚠️ 关于备案（重要）

- **国内服务器**（北京/上海/广州等）：域名必须 **ICP 备案**，否则 80/443 端口会被运营商拦截。备案免费但要 **1–3 周**。
- **香港/海外服务器**（腾讯云香港、阿里云香港、Vultr）：**不需要备案**，买完就能用。国内访问速度稍慢（几十毫秒），完全够用。
- 微信小程序正式版**要求备案域名**；**手机 App 不要求**。

👉 **想尽快跑通，建议先买香港轻量服务器。**

---

## 第 1 步：买服务器

以腾讯云轻量应用服务器为例：

1. 打开 <https://cloud.tencent.com/> → 登录 → 「产品」→「轻量应用服务器」
2. 点「新建」：
   - 地域：**香港**（免备案）或就近的国内地域（需备案）
   - 镜像：**Ubuntu 22.04 LTS**（纯系统镜像，不要选应用镜像）
   - 套餐：**2核 2G / 40G SSD** 足够
3. 购买后进入实例详情，记下：
   - **公网 IP**（例如 `43.129.xx.xx`）
   - **root 密码**（首次可在控制台"重置密码"）

---

## 第 2 步：放行防火墙端口（最容易漏！）

云厂商默认只开 22 端口，**80/443 必须手动放行**，否则网站打不开。

腾讯云轻量：

1. 实例详情 → 「防火墙」标签
2. 点「添加规则」：
   - 应用类型：**HTTP (80)**，来源 `0.0.0.0/0`
   - 应用类型：**HTTPS (443)**，来源 `0.0.0.0/0`
3. 保存（立即生效）

阿里云轻量：实例 → 「防火墙」→ 添加 80、443。

> 阿里云 ECS 还要在「安全组」里放行同样的端口。

---

## 第 3 步：连接服务器

在 Windows 上按 `Win + R`，输入 `cmd` 回车，然后：

```cmd
ssh root@你的服务器公网IP
```

- 第一次连接会提示 `Are you sure you want to continue connecting?` → 输入 `yes` 回车
- 然后输入密码（**输入时不显示字符，输完直接回车**）

连上后提示符会变成类似：

```
root@VM-0-2-ubuntu:~#
```

> 如果提示 `ssh 不是内部或外部命令`：用 PowerShell 代替 cmd，或安装 PuTTY / MobaXterm。

---

## 第 4 步：上传代码

### 4.1 在你电脑上（**新开一个** cmd 窗口，不要关掉 ssh 那个）

我打包好的文件在：`D:\y\1\发布\esim-源码.tar.gz`（109 KB）

```cmd
scp D:\y\1\发布\esim-源码.tar.gz root@你的服务器IP:/opt/
```

输入密码后开始上传，几秒钟完成。

### 4.2 回到 ssh 窗口，解压

```bash
cd /opt
tar xzf esim-源码.tar.gz -C /opt
ls /opt
```

应该看到 `src  server  deploy  public  index.html  vite.config.js  package.json ...`

> 如果 `tar` 报错说文件不存在，检查 4.1 是否成功；也可以先在 `/opt` 建目录：
> `mkdir -p /opt/esim && tar xzf /opt/esim-源码.tar.gz -C /opt`

---

## 第 5 步：配置域名解析

**有域名就做这步；没有域名跳到第 5.2 用 IP 测试。**

### 5.1 加 A 记录

进你买域名的控制台（腾讯云 DNSPod / 阿里云云解析）：

| 记录类型 | 主机记录 | 记录值 |
|---|---|---|
| A | `@` | 你的服务器公网 IP |
| A | `www` | 你的服务器公网 IP |

保存后等 1–10 分钟，在你电脑上验证：

```cmd
ping 你的域名
```

返回的 IP 是服务器 IP 就对了。

### 5.2 只有 IP、没有域名

见文末「附录 A：不用域名，直接用 IP 访问」。

---

## 第 6 步：填写配置并部署

在 ssh 窗口里：

```bash
cd /opt/deploy
cp .env.example .env
vi .env
```

`vi` 的操作（新手必看）：

1. 按 **`i`** 进入编辑模式（左下角出现 `-- INSERT --`）
2. 把 `DOMAIN=esim.example.com` 改成 **你的域名**，把 `EMAIL=` 改成你的邮箱
3. 按 **`Esc`** 退出编辑
4. 输入 **`:wq`** 然后回车（保存并退出）

改完应该是这样：

```
DOMAIN=esim.你的域名.com
EMAIL=你的邮箱@qq.com
NPM_REGISTRY=https://registry.npmmirror.com
```

然后执行一键部署：

```bash
bash deploy.sh
```

脚本会自动做这些事（约 3–8 分钟，主要看网速）：

```
检查/安装 Docker
放行 80/443
构建镜像（装依赖 → 构建前端 → 精简运行镜像）
启动 app + caddy 两个容器
自动申请 HTTPS 证书
健康检查
```

看到这个就成功了：

```
=== 部署完成 ===
  平台地址   https://你的域名
  后台数据   https://你的域名/admin
  健康检查   https://你的域名/api/health
```

---

## 第 7 步：验证

在你电脑的浏览器里打开：

1. **`https://你的域名/api/health`**
   应返回 `{"ok":true,"service":"electric-sim-platform-server",...}`

2. **`https://你的域名`**
   应看到 3D 实验平台（地址栏有小锁 = HTTPS 正常）

3. **`https://你的域名/admin`**
   教师后台登录页

> 首次访问可能等 10–30 秒（正在申请证书），如果报证书错误，等一分钟重试。

## 第 9 步：手机 App 填地址

1. 手机装 `电工电子实训-v1.4.apk`
2. 打开 App → 顶栏 **⚙**
3. 地址填：`https://你的域名`
4. 点 **测试连接** → 显示"连接成功 · electric-sim-platform-server v2.0.0"
5. 点 **保存**

之后：

- 顶栏出现 **👤 登录**，用 `laoshi / 123456` 登录
- 记录数据、提交报告都会存到服务器
- **电脑关机、换手机，数据都还在**

## 第 10 步：日常运维

```bash
cd /opt/deploy

docker compose ps                 # 看容器状态
docker compose logs -f app        # 看后端日志（Ctrl+C 退出）
docker compose restart app        # 重启后端
docker compose down               # 停止（数据不丢）
docker compose up -d              # 重新启动
docker compose up -d --build      # 更新代码后重新构建
```

**备份数据库**（建议每周一次）：

```bash
bash backup.sh backup
# 生成 backup-2026-01-01-1200.db
```

下载到本地：

```cmd
scp root@服务器IP:/opt/deploy/backup-*.db D:\
```

**恢复**：

```bash
bash backup.sh restore backup-2026-01-01-1200.db
```

**更新代码**（你改了前端/后端之后）：

```cmd
:: 在电脑上重新打包
cd /d D:\y\1
tar -czf D:\y\1\发布\esim-源码.tar.gz src server deploy public index.html vite.config.js package.json package-lock.json .dockerignore
scp D:\y\1\发布\esim-源码.tar.gz root@服务器IP:/opt/
```

```bash
# 服务器上
cd /opt && tar xzf esim-源码.tar.gz
cd deploy && docker compose up -d --build
```

## 第 11 步：排错对照表

| 现象 | 原因 | 解决 |
|---|---|---|
| 浏览器打不开域名 | 安全组没放行 80/443 | 回到**第 2 步** |
| `ping 域名` IP 不对 | DNS 没生效 | 等 10 分钟；检查 A 记录 |
| 提示连接不安全 / 证书错误 | 证书还在申请 | 等 30 秒重试；`docker compose logs caddy` |
| `502 Bad Gateway` | 后端容器没起来 | `docker compose logs app` |
| `deploy.sh` 卡在拉镜像 | 国内拉 Docker Hub 慢 | 见「附录 B：配置镜像加速」 |
| 备案未通过、80 被拦 | 国内服务器限制 | 换香港服务器，或先用 IP 直连测试 |
| App 里"连不上" | 域名/端口错，或没填 `https://` | 地址要带 `https://`，末尾不要加斜杠 |
| 登录成功但看不到记录 | 正常，新账号没有数据 | 先做实验并点「记录数据」 |

## 附录 A：不用域名，直接用 IP 访问

没有域名也能跑（但没有 HTTPS，微信小程序用不了，App 可以）：

```bash
# 1. 修改 deploy/docker-compose.yml，把 app 端口暴露出来
cd /opt/deploy
vi docker-compose.yml
```

在 `app:` 服务里把

```yaml
    expose:
      - "3001"
```

改成

```yaml
    ports:
      - "3001:3001"
```

并注释掉整个 `caddy:` 服务（在每行前加 `#`，或直接删除该段）。

```bash
# 2. 重新启动
docker compose up -d

# 3. 访问
http://你的服务器IP:3001
```

App 里填 `http://你的服务器IP:3001`。

## 附录 B：Docker 镜像加速（构建慢时用）

```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<'EOF'
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://dockerproxy.com"
  ]
}
EOF
sudo systemctl daemon-reload
sudo systemctl restart docker
```

## 附录 C：改成你自己的密码

```bash
docker exec -it esim-app node -e "
  const { scryptSync, randomBytes } = require('node:crypto')
  const { DatabaseSync } = require('node:sqlite')
  const db = new DatabaseSync('/app/server/data/app.db')
  const pwd = '换成你的新密码'
  const salt = randomBytes(16).toString('hex')
  const hash = scryptSync(pwd, salt, 64).toString('hex')
  db.prepare('UPDATE users SET password_hash = ?, salt = ? WHERE username = ?').run(hash, salt, 'laoshi')
  console.log('已修改 laoshi 的密码')
"
```

## 附录 D：服务器重启后会自动运行吗

会。`docker-compose.yml` 里两个容器都设置了 `restart: unless-stopped`，
并且 Docker 服务默认开机自启，所以**服务器重启后平台自动恢复**，不用手动操作。
