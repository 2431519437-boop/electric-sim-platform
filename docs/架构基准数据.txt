  总耗时：1014.6 ms
  平均：2.255 ms/组
  P50：1.701 ms　P95：4.543 ms　最大：10.426 ms
  吞吐：444 组/秒

  总耗时：947.8 ms
  单次写：0.474 ms
  事件循环探针最大延迟：0.000 ms（无阻塞）

【3】并发判分吞吐（100 组并发）
  并发数：100
  总耗时：224.2 ms
  平均每组：2.242 ms
  有效吞吐：446 组/秒

结论：
  - 单组判分 < 10ms，450 组全链验证秒级完成，满足课室规模（<100 人）实时判分。
  - SQLite 同步写单次 < 0.1ms，事件循环无阻塞（WAL 模式 + 单进程可接受）。
  - 单进程 CPU 密集判分在并发下线性排队，课室规模够用；若需跨机房可加进程池。
