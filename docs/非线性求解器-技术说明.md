# 非线性直流求解器技术说明

> 算法创新点：Newton-Raphson 迭代 + Shockley 二极管模型，逼近 SPICE/Multisim 的非线性器件仿真能力

---

## 1. 问题背景

原直流求解器（`circuitCore.js`）对 LED 采用「分段线性」简化模型：

```
I = (U − Vf) / Rf   （当 U > Vf）
I = 0               （当 U ≤ Vf）
```

这是**理想二极管 + 串联电阻**的近似，存在两个本质缺陷：

1. **硬截止**：电压低于 Vf（1.8V）时电流被强行判为 0，无法还原二极管在阈值附近的「软开启」指数特性。
2. **线性化失真**：导通后 I–V 是一条直线，而真实 PN 结是指数曲线。

这是逼近 Multisim 路上最大的算法短板——**非线性器件建模**。

## 2. 模型：Shockley 方程

本模块用 PN 结的 **Shockley 方程**精确建模二极管/LED：

```
I_d = I_s · ( e^{ V_d / (n·V_T) } − 1 )

其中  V_T = kT/q ≈ 25.85 mV  （室温热电压）
      I_s = 反向饱和电流（~1e-12 A）
      n   = 理想因子（LED 典型 2~4，本平台取 3）
```

LED 被建模为「结二极管 + 串联体电阻 rs」的**组合**（SPICE 标准做法）：

```
LED(A 阳极) ──[结二极管 Shockley]── M(内部节点) ──[体电阻 rs]── K(阴极)
```

## 3. 算法：Newton-Raphson 迭代（MNA + 逐次线性化）

非线性方程组无法直接高斯消元，采用 **Newton-Raphson**：

1. 对每个二极管，在当前工作点 V_d^(k) 做**一阶泰勒线性化**：
   - 等效电导（companion conductance）：`G_eq = g'(V_d) = (I_s/(n·V_T))·e^{V_d/(n·V_T)}`
   - 诺顿等效历史电流：`J_eq = g(V_d) − g'(V_d)·V_d`

2. 把二极管替换成「G_eq + J_eq」，电路退化为**线性电阻网络**，用 MNA + 全主元高斯消元求解。

3. 用新解的结电压更新 V_d，重复迭代直到收敛（相对增量 < 1e-9）。

## 4. 数值稳健性（关键工程点）

Newton 迭代对二极管这类**指数型非线性**有经典难点：远离解时步长会爆炸（exp 溢出），必须加限幅。本实现：

| 措施 | 作用 |
|---|---|
| **正向限幅** | 结电压钳制在 `vf + 1.0`（约 2.8V）以内，防止 `e^{Vd/(n·Vt)}` 溢出到 Infinity |
| **反向硬截止** | Vd < −0.5V 时 gd 直接置 0，避免极小电导（~1e-17）导致的矩阵病态 |
| **阻尼 damping** | 可调阻尼因子，增强远解点的稳健性 |
| **内部节点拆分** | 结二极管与体电阻 rs 拆成两个支路，避免隐式方程的病态 |

## 5. 对比实验数据（详见 `非线性求解器-对比实验数据.txt`）

### 5.1 伏安特性：简化模型 vs Shockley 模型（200Ω 限流）

| 电源电压 | 简化 I(mA) | Shockley I(mA) | 相对误差 |
|---|---|---|---|
| 1.5V | 0（硬截止） | 0.222（软开启） | — |
| 2.0V | 0.909 | 1.765 | 94% |
| 3.0V | 5.455 | 5.886 | 7.9% |
| 6.0V | 19.091 | 19.107 | **0.1%** |
| 10.0V | 37.273 | 37.055 | −0.6% |

**结论**：
- 开启区（1.5~2V）两模型差异显著，Shockley 还原了真实的「软开启」指数爬升。
- 额定工作区（6V，误差 0.1%）两模型高度一致，**保证升级建模不破坏现有判分**。

### 5.2 收敛曲线（Newton-Raphson）

```
迭代 | 结电压 Vd(V) | 残差 |f|
  ...
 15   |     1.803539 |    2.51e+0
 16   |     1.796766 |    4.09e-1
 17   |     1.796458 |    1.71e-2
 18   |     1.796458 |    3.32e-5
 19   |     1.796458 |   1.27e-10
 20   |     1.796458 |   3.55e-15
```

**二次收敛证据**：接近解后残差呈平方级下降（`1.7e-2 → 3.3e-5 → 1.3e-10 → 3.6e-15`），
`|f_{k+1}|/|f_k|² ≈ 0.11` 趋于常数，这是 Newton-Raphson 二次收敛的教科书级特征
（每步有效数字翻倍）。

## 6. 与现有求解器的关系（并存不替换）

| 求解器 | 适用场景 | 状态 |
|---|---|---|
| `circuitCore.solveCircuit` | 纯电阻/简化 LED 直流电路 | 保留（判分主路径） |
| `acSolver.solveAC` | 正弦稳态（相量） | 保留 |
| `transientSolver.solveTransient` | RC/RL 瞬态 | 保留 |
| **`nonlinearSolver.solveNonlinearDC`** | **含 LED 的精确直流解** | **新增（增强）** |

非线性求解器作为**增强结果**并入 `analysis.js` 的 `solution.nonlinear` 字段，
不改动 `branchCurrents`（LED 仍走简化模型判分），保证 450 组判分验证零回归。
