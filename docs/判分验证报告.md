## 5. 极性检测机制验证

串联/并联两个实验的标准答案存在对称性（见第 6 节），会把"电源接反"吸收为等价接法。
为证明**极性检测本身有效**，另用一份含方向性元件（LED）的非对称标准答案单独验证：

| 用例 | 期望 | 实际 | 结果 |
|---|---|---|---|
| 方向完全正确 → 应判通过 | — | 接线与标准串联回路完全等价（图同构匹配成功） | ✓ 通过 |
| 仅电源接反 → 应判不通过且报极性反 | — | ok=false polarityReversed=true | 接线拓扑正确，但电源极性接反（V+ 与 V- 对调） | ✓ 通过 |
| 缺 LED → 应报缺少元件 | — | 回路中缺少发光二极管 | ✓ 通过 |

结论：方向比对逻辑（`edgesCompatible` 中对 `directed` 参考边比较端点朝向）工作正常，
在非对称拓扑中能准确报出「电源极性接反」。

## 6. 关于"极性接反"判定口径的说明

三个实验对「极性接反」的处理不同，这是**拓扑等价**决定的，不是缺陷：

| 实验 | 接反后的判定 | 原因 |
|---|---|---|
| 串联分压 | ✅ 通过 | 接反与「R1/R2 换位」的标准答案同构；串联回路互换电阻位置，电压电流幅值完全相同 |
| 并联分流 | ✅ 通过 | 并联只有两个电气节点，接反 = 交换节点标号，是同一张图的自同构 |
| **LED 限流** | ❌ **不通过，报极性反** | 标准答案含方向性元件 LED，接反后无法被任何对称性吸收 |

前两个实验按平台既定原则「电气等价即通过」判通过是自洽的；
LED 实验则因为 LED 必须正向导通，极性接反会真实导致不导通，必须判错。

**结论**：极性检测不是"时灵时不灵"，而是**取决于标准答案里有没有方向性约束**。
这也说明为什么第 5 节的机制验证要单独做 ---- 它把"机制有效"与"被对称性吸收"两件事分开了。

若要前两个实验也严格要求正接，正确做法不是在图同构里加特例，而是：
1. 在标准答案中加入 LED 等方向性元件；或
2. 把"仪表正负极性"单独作为一项检查（与拓扑判定解耦）。

## 7. 判定口径说明

| 结论 | 判定依据 |
|---|---|
| 通过 | 学生电路与标准答案图**图同构**（顶点双射、边同标签、电源方向一致） |
| 不通过 - 缺元件 | 回路连通分量中缺少必需类型 |
| 不通过 - 未闭合 | 存在度数 < 2 的悬空端，或边数不足 |
| 不通过 - 多接 | 连通分量中存在标准答案没有的元件类型 |
| 不通过 - 参数错 | 结构匹配但元件参数超出容差（标准值 ± 容差） |
| 不通过 - 极性反 | 放开方向后能匹配，说明拓扑对但电源接反 |
| 不通过 - 结构错 | 以上均不成立（如串联接成并联） |
